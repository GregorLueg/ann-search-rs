## MLX indices benchmarks and parameter gridsearch

Experimental. The same benchmarks as [the GPU ones](benchmarks_gpu.md), run on
the MLX backend instead of wgpu. MLX drives Metal directly through mlx-c, so
this is Apple Silicon only, f32 only, and needs the `mlx` feature plus an
installed mlx-c (`brew install mlx-c`). Exhaustive and IVF:

```bash
cargo run --example gridsearch_mlx --features mlx --release
```

For the CAGRA style search:

```bash
cargo run --example gridsearch_cagra_mlx --features mlx --release
```

The parameters and data match the wgpu runs one to one, so the tables can be
read side by side with [the GPU benchmarks](benchmarks_gpu.md). There is no MLX
NSG path.
